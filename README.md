# piptree

## How to setup?

1.

Get setup.ps1 and piptree.py into a folder in your computer where the paths will not change with time.

Do this by download zip file from this repository. Or do this by downloading only the setup.ps1 and piptree.py

2.

Then execute the powershell script in the working directory of the setup.ps1 and piptree.py


## How to use ?

Write: "piptree \<python package or module\>"

for example:
* piptree math
* piptree numpy
* piptree os
